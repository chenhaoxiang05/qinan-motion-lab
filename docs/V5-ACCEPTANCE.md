# v5 浏览器验收（待执行）

当前状态：代码和自动化验证完成；真实浏览器截图、动效录像、GPU 观感与性能尚未验证。下面各项不能以 JSDOM 的结果代替。

## 页面与可见性

在现代 Chromium 和 Safari/WebKit 中检查；视口至少覆盖 320、390、768、1440px。

- 首页标题、盾牌、操作按钮与四个入口互不遮挡，页面没有横向溢出。移动端滑动时盾牌跟随预留区域。
- 各入口展开后，标题、主要正文、返回按钮可见。逐项检查 computed opacity 与所有祖先的 visibility，文字边界必须非零且在可滚动区域内。
- 作答一题，返回主页，再进入练习：已选答案和解析保持显示，不能重新变透明。
- 设置刚打开立即关闭，暂停动效后重开：弹窗为不透明、正常尺寸；设置、帮助、示例和删除确认均可按 Esc 关闭。
- 连续打开/返回 20 次、展开中 Esc、收回中导航、浏览器前进/后退、中途暂停、切后台、旋转/缩放窗口：无残留遮罩或不可见正文。
- 照片/视频/声音/截图切换不重放窗口动画，不出现全屏白闪。

## 功能回归

- 上传有效文件、格式不符、空文件、超过限制视频，替换与删除预览；旧视频校验不能覆盖新照片。
- 联系人新增、重复号码校验、删除取消/确认、刷新后保留；拨号链接正确。
- 完成六题、重复点击答案、查看解析、重新练习；进度退场不影响正文显示。
- 演示核验过程中离开页面，完成结果不得强行跳转；历史与保存报告能重新打开。
- 真实模式后端未连接时显示错误，不无限加载；返回演示模式时不被旧响应覆盖。
- 报告导出/打印内容完整，交互浮层不进入打印输出。

## 场景与无障碍

- 录制盾牌 → 标语 → 盾牌全程：分解、迁移、归位有清楚节奏；成字后停止转动，方块间隙可辨，字形孔洞保留。
- 切换期间暂停、打开窗口、切后台，以及跨 700px 断点：立即落到有效形态，按钮能继续使用。
- 无 WebGL 时仍有盾牌/六字 SVG；场景加载失败时 CSS 占位与切换按钮可用。
- reduced-motion 和手动暂停禁用持续运动，功能不受影响；键盘能到达全部入口，关闭弹窗后焦点回到合理位置。
- 观察控制台和性能记录，确认没有 shader 编译错误、未处理异常或持续增长的资源。记录浏览器、设备及实际帧率，不填写推测结果。
