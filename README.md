# 亲安 QINAN · Motion Lab

奶油白、荧光绿与深墨绿，悬浮立体安全盾牌、轨道、扫光、粒子、鼠标跟随、波形动效、页面入场和微交互。使用原生 HTML/CSS/JavaScript，无需安装依赖或构建。

## 本地运行

```bash
cd /workspace/sites/qinan
python3 -m http.server 5173 -d dist
```

打开 http://localhost:5173 。静态产物位于 `dist/`，可直接交给任意静态服务器。

```bash
npm run check
```

字体通过 Google Fonts 加载，离线时回退系统字体。

## 功能与范围

- 首页：悬浮盾牌、轨道、粒子和鼠标交互，支持暂停动效及系统减少动态偏好。
- 上传：声音、视频、图片、聊天截图，拖放/系统选择、本地预览、100MiB 上限、可读取视频的 3 分钟限制。
- 演示：默认模式不上传文件，展示明确标注的虚构报告；波形是装饰动画，不是文件的真实波形。
- 家人：保留 `qinan-contacts` 键和 `[{name,phone}]` 结构；添加、确认删除、tel 拨号。
- 练习：6 个虚构情景，单次作答、正确答案、解析、错题总结、重新开始。
- 记录：演示记录使用独立本地存储；查看、JSON 下载、打印。
- 适配：桌面侧边导航、平板紧凑导航、手机底部导航，键盘焦点及原生 dialog。

本次重点是视觉动效和核心交互，不是交接文档所有功能的等价替换。未实现新闻、研究实测、聊天 OCR 编辑重查、详细采样图与真实演示素材下载；实际报告保留完整返回数据以便接入扩展。

## 真实接口

右上角可切换真实接口。托管预览不含 FastAPI、数据库或检测模型，真实模式不会伪造结果。将 `dist/` 放到原后端同源服务，或配置 `/api` 反向代理。浏览器使用相对 URL：

- GET /api/health
- POST /api/analyze，FormData: file、scene、context
- GET /api/jobs/{job_id}，1.5 秒轮询，sessionStorage 恢复任务
- GET /api/cases
- GET /api/cases/{id}

实际报告展示各模块状态、分数、各自阈值、聊天 assessment/signals 及完整原始记录，导出所有返回字段。检测分数不是诈骗概率。
