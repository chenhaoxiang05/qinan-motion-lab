# 亲安 QINAN · 安心引力场 v2

基于亲安的反诈核验场景重新设计的互动前端。取消侧边栏，使用四个悬浮入口进入功能窗口。主页面保留为一个持续存在的空间。

## 启动与构建

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
npm run check
npm test
npm run build
```

开发地址由 Vite 输出。`dist/` 是完整静态产物，可以直接交给静态服务器或原后端托管。路由使用 hash，不需要服务器配置路由回退。

## 视觉与交互

- Three.js 程序生成的金属质感环结、表面光带、粒子与环绕轨道，不依赖远程模型或纹理。
- 拖动核心旋转；点击按钮打散粒子，再通过弹簧动画聚合。
- Anime.js 控制悬浮入口、鼠标磁吸、弹性回位和窗口进出。参考用户给出的 `utilities.remove()` 示例，在重建动画前精确移除旧属性动画。
- 3D 引擎单独按需加载，界面先就绪；WebGL 不可用时保留 CSS 图形和全部功能。
- 桌面悬浮卡片，手机双列入口。系统减少动态偏好、手动暂停、页面隐藏暂停渲染。
- 字体、动画库、3D 引擎随产物发布。中文使用本机系统字体，运行时没有外部字体请求。

## 修复

- **同页切换闪白**：声音、视频、照片、截图切换只更新选中态、提示和文件区域；窗口、上传面板、上传容器保持同一 DOM 实例，不重播入场动画。
- **切走后被抢回页面**：演示结束后仅在仍查看核验时打开报告，否则保存在记录中并提示。
- **异步旧结果覆盖**：页面请求带取消信号和视图版本检查；旧历史或健康请求不会改写新页面/新模式。
- **视频校验竞态**：替换文件或模式时释放旧校验；旧视频结果不会清掉新照片。校验期间禁用提交。
- **暂停造成页面不可见**：仅暂停持续动效，窗口入场会完成。暂停状态下打开内容立即可见。
- 联系人数量即时更新，重复号码提示，确认删除；损坏或非数组存储可安全回退。
- 保存报告可通过 hash 路径刷新恢复；真实报告按模块及片段自己的阈值解释。
- 原生弹窗支持 Escape、焦点约束；材料类型支持方向键；文件播放器与选择文件操作独立。

## 功能范围

上传本地预览、类型/大小/视频时长检查；虚构示例报告；联系人本地保存与 tel 拨号；6 个情景练习与错题总结；核验记录、JSON 导出和打印。

默认演示模式，文件不会上传，报告明确标注虚构示例。波形为装饰，不是上传文件的实际波形。

保留联系人存储键 `qinan-contacts` 和结构 `[{name,phone}]`，可直接读取上一版联系人。演示报告独立存储在 `qinan-demo-history`。

## 真实接口

右上角设置可切换真实接口。托管预览未包含 FastAPI、数据库或模型服务。

部署到原后端同源服务，或为 `/api` 配置反向代理后使用：

- `GET /api/health`
- `POST /api/analyze`，FormData: file、scene、context
- `GET /api/jobs/{job_id}`，1.5 秒轮询，sessionStorage 恢复
- `GET /api/cases`
- `GET /api/cases/{id}`

真实报告显示各模块状态、分数、各自阈值、聊天 assessment/signals 和完整原始记录。实际模型未在本环境运行。

本次仍以视觉和核心交互为范围，不是交接文档的全功能替换。新闻、研究实测、OCR 编辑重查、详细采样图、真实样例下载尚未实现。

## 验证

14 项 DOM / 回归检查通过，其中包含真实 Anime.js 引擎的窗口进出、暂停与类型切换检查；覆盖局部更新、旧请求、视频校验竞态、联系人、答题、任务完成时导航、存储恢复、各自阈值。生产构建与语法检查通过。

当前环境浏览器工具初始化报错 `the gaas-browser node_repl sandbox cannot be disabled`，因此没有完成 WebGL 实际渲染截图和浏览器跨设备视觉验收。DOM 测试不能代替这些视觉检查。

## 源码

- `src/app.js`：路由、表单、异步任务和报告。
- `src/scene.js`：3D 核心、粒子、渲染生命周期。
- `src/style.css`：布局、组件、响应式和打印样式。
- `src/main.js`：界面启动与 3D 懒加载。
- `tests/`：交互与动画集成回归检查。

字体与依赖分别遵循其许可证；DM Sans 的 OFL 许可随产物提供。
